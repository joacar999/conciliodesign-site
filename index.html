About

Concilio Design is an independent integration and software engineering studio focused on API integration, automation and AI-assisted development tools.

The studio is owned and operated by Joakim Carlsson, founder and CEO of Concilio Design AB, a senior integration consultant with experience from enterprise systems, cloud integration, backend engineering and API security.

Current focus areas include OpenAPI tooling, Python integration frameworks, AI-assisted engineering workflows and developer productivity applications.
